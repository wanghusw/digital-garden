## 碎片想法

一个思考：一个短途旅行的照片或者是一个规划了很久的旅行的照片，是该保存在所有照片的集合还是说保存在这个旅行的id文件夹下面？

## Tips

### 为什么使用子文件夹（这里的子文件夹指的是 ID 下的子文件夹）是有意义的？

因为这样更整洁。

> I used to be anti-subfolder. But sometimes one more level (and I mean one) of subfolders makes sense. 我以前反对使用子文件夹。但有时候多一个层级（而且我指的是一个层级）的子文件夹是有意义的。
> 
In the example above, we could have saved all the insurance claim documents in the main folder. But it was neater to create a new subfolder. 在上面的例子中，我们可以将所有保险索赔文件保存在主文件夹中。但创建一个新的子文件夹更整洁。
>

### 关于索引

索引可以添加位置和关键词，在必要的时候用 `[[]]` 给 ID 创建单独笔记即可。2026-04-28 14:48:57

在 ID 文件夹下的子文件夹命名可以是：
```
10-xx
20-xx
30-xx
```
或者：
```
yyyy-mm-dd-xx
```

可以为 ID 笔记创建元数据，如 Description（📝）、Location（📍）、Relates to（🔗）、Keywords（🔑）

### 关于 `0`

#### ID 

- .00 特定的索引数据
- .01-inbox 每个类别下想尽快整理的东西，收件箱里的东西要尽快整理
- .02-task&project
- .03-templates 关注 90.03
- .04-links 作者在这里整理浏览器书签，这是一个很好的启发
- .05 .06 .07 保留用于扩展
- .08-someday 与 `.01-inbox` 类似，但不急着整理，而是总有一天会被分类，如果没有，那可能要考虑放到存档去。我从 [Customizing the standard zeros - The Johnny.Decimal system - Johnny.Decimal forum](https://forum.johnnydecimal.com/t/customizing-the-standard-zeros/2160/3) 看到有人的设定是 `.08-resources`，这是一个可以参考的想法。2026-04-28 17:44:14
